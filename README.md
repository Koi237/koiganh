A website to play cờ gánh - a traditional Vietnamese chess game. 
There two game modes: multiplayer with sent invite via link sharing. powered via Metered turn sever; And versus mode against bot opponents with the design philosophy of mimicing human opponents.
The documentation of bot's algorithm design can be found at https://docs.google.com/document/d/1RRPHi55t95Z42GmdxdaAWDE12MJEmd8S_yv04EvPqi8/edit?usp=sharing
